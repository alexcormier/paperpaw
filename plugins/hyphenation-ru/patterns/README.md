# Hyphenation patterns for Russian

The pattern files `hyph-ru.pat.txt` and `hyph-ru.hyp.txt` are taken
unchanged from the hyph-utf8 project
(https://github.com/hyphenation/tex-hyphen,
`hyph-utf8/tex/generic/hyph-utf8/patterns/txt`). The build script compiles
them into a table for `paperpaw-hyphen`.

Hyphenation patterns for Russian, version 2003/03/10, by Alexander I.
Lebedev. Licence: LaTeX Project Public License 1.2 or later (used under
1.3c). Hyphen minimums: 2 characters before, 2 after.
