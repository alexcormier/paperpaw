# Hyphenation patterns for Norwegian Bokmål

The pattern files `hyph-nb.pat.txt` and `hyph-nb.hyp.txt` are taken
unchanged from the hyph-utf8 project
(https://github.com/hyphenation/tex-hyphen,
`hyph-utf8/tex/generic/hyph-utf8/patterns/txt`). The build script compiles
them into a table for `paperpaw-hyphen`. The table also serves the language
tag `no`.

Hyphenation patterns for Norwegian Bokmål, version 2007-02-10, by Rune
Kleveland, Ole Michael Selberg, Karl Ove Hufthammer. Licence: the authors'
own terms, below. Hyphen minimums: 2 characters before, 2 after.
