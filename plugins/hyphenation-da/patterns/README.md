# Hyphenation patterns for Danish

The pattern file `hyph-da.pat.txt` is taken unchanged from the hyph-utf8
project (https://github.com/hyphenation/tex-hyphen,
`hyph-utf8/tex/generic/hyph-utf8/patterns/txt`). The build script compiles
it into a table for `paperpaw-hyphen`.

Hyphenation patterns for Danish, version 2011-01-11, by Frank Jensen.
Licence: MIT (the authors offer the LPPL 1.3 or later as well). Hyphen
minimums: 2 characters before, 2 after.
