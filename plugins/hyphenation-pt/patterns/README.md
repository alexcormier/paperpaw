# Hyphenation patterns for Portuguese

The pattern files `hyph-pt.pat.txt` and `hyph-pt.hyp.txt` are taken
unchanged from the hyph-utf8 project
(https://github.com/hyphenation/tex-hyphen,
`hyph-utf8/tex/generic/hyph-utf8/patterns/txt`). The build script compiles
them into a table for `paperpaw-hyphen`.

Hyphenation patterns for Portuguese, version 1.4 2024-07-13, by Pedro J. de
Rezende, J. Joao Dias Almeida, Leonardo Araujo, Aline Benevides. Licence:
the authors' own terms, below. Hyphen minimums: 2 characters before, 3
after.
