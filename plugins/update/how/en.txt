Update installs new firmware, on devices where PaperPaw is the firmware, such as the X4. You find it in the settings, as Update.

Search online asks the update server for a newer PaperPaw and downloads it, which takes a few minutes over Wi-Fi. Or copy an update file (ending in .bin, from paperpaw.org) into the folder updates on the card, for example with Wi-Fi transfer. Install then takes about a minute and the device restarts; books, settings and reading positions stay.

With Look for updates on (in the settings, off at first), the device asks about once a week by itself, only while Wi-Fi is on anyway or it charges. A newer PaperPaw it finds waits here, marked New in the settings; nothing interrupts your reading. A search sends what the device runs, no name or number of it; to count devices, also whether you asked and whether it is its first search of the day, week or month.

If plugins you use have no version for the new release yet, you can wait for them or update without them. An older version installs only if you choose it.

Another firmware, such as CrossPoint, installs from here too: put its file (ending in .bin) at the top of the card or in updates, and open Update. PaperPaw checks that it is a whole firmware for this device, undamaged, but cannot tell who made it, since it is not signed. Install anyway writes it into the other half of the flash, and the device starts it; PaperPaw stays in its half until that firmware installs something over it. To return to PaperPaw later, install its install file (paperpaw-<device>-<version>-install.bin) from the other firmware's menu, such as CrossPoint's SD firmware update.
