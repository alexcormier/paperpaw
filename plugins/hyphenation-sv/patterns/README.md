# Hyphenation patterns for Swedish

The pattern file `hyph-sv.pat.txt` is taken unchanged from the hyph-utf8
project (https://github.com/hyphenation/tex-hyphen,
`hyph-utf8/tex/generic/hyph-utf8/patterns/txt`). The build script compiles
it into a table for `paperpaw-hyphen`.

Hyphenation patterns for Swedish, version 1994-03-03, by Jan Michael
Rynning. Licence: LaTeX Project Public License 1.2 or later (used under
1.3c). Hyphen minimums: 2 characters before, 2 after.
