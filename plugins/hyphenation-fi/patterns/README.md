# Hyphenation patterns for Finnish

The pattern file `hyph-fi.pat.txt` is taken unchanged from the hyph-utf8
project (https://github.com/hyphenation/tex-hyphen,
`hyph-utf8/tex/generic/hyph-utf8/patterns/txt`). The build script compiles
it into a table for `paperpaw-hyphen`.

Hyphenation patterns for Finnish, version 2.2, by Kauko Saarinen. Licence:
the authors' own terms, below. Hyphen minimums: 2 characters before, 2
after.
