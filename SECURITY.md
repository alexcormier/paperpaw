# Security Policy

PaperPaw opens untrusted files (books, fonts, images) and runs third-party
plugins, so we take security reports seriously. What it protects, and
against whom, is in the [security model](docs/security-model.md).

## Reporting a vulnerability

Please **do not open a public issue.** Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/hthoene/paperpaw/security/advisories/new).

Include what you can: affected version or commit, device or emulator profile,
a sample file or steps to reproduce, and the impact you expect.

We aim to acknowledge reports within a week and will keep you informed while
we work on a fix. Credit is given in the release notes unless you prefer
otherwise.

## Supported versions

PaperPaw is in beta (0.5.0-beta.6). Until 1.0, only the latest `main` branch
receives security fixes.
